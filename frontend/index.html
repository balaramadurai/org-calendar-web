Filter syntax help

Fields: duration, priority, category, title, allday

Operators: =, !=, >=, <=, >, <, IN, NOT IN, CONTAINS

Logic: AND, OR (evaluated left to right)

Examples:

duration >= 3h
duration >= 2h OR priority = A
category IN (Travel, Holiday, Workshop)
category NOT IN (Birthday, Reminder)
title CONTAINS retreat
allday = true AND duration >= 1h
